# 02 – Individual Exercise: Figma to Lovable Workflow

## 💡 Why this exercise matters
This workflow bridges **Figma’s structured design environment** with **Lovable’s AI prototyping power**.  
You’ll learn how to turn low-fidelity wireframes into realistic prototypes with minimal effort.

## 🎯 Expected outcomes
- Figma wireframes converted into functional prototypes  
- Modern, interactive UI built from your design flow  
- Efficient transition from design to testing

---

## 🧩 Step 1: Install Wireframe Designer Plugin
1. In Figma: Plugins → Browse all plugins  
2. Search: "Wireframe Designer"  
3. Install and open the plugin

---

## 🧩 Step 2: User Flow Prompting Template

Create wireframes for this user flow:

PRODUCT CONTEXT:
App Name: [Your product name]
User Type: [Primary persona]
Main Job-to-be-Done: [What users are trying to accomplish]

USER FLOW STEPS:
1. Entry Point: [How users discover/access the feature]
   - Page elements needed: [navigation, hero, etc.]

2. Discovery Phase: [How users understand what's available]
   - Page elements needed: [search, categories, filters]

3. Action Phase: [Core interaction/task completion]
   - Page elements needed: [forms, buttons, confirmation]

4. Outcome Phase: [Success state and next steps]
   - Page elements needed: [results, sharing, navigation]

WIREFRAME REQUIREMENTS:
- Low-fidelity, focus on layout and flow
- Include all necessary UI components
- Show responsive behavior for mobile and desktop
- Add annotations for interactions and state changes

---

## 🧩 Step 3: Export to Lovable Instructions
1. Export from Figma:  
   - Select wireframe frames  
   - Right-click → Export → PNG (2x resolution)  
   - Save with clear names  
2. Upload to Lovable:  
   - Open Lovable.dev → Upload images  
3. Enhancement Prompt:

Convert these wireframes into a fully functional prototype:
- Transform wireframe elements into modern, interactive components 
- Add realistic content and data where placeholders exist 
- Implement the user flow with proper navigation between screens 
- Include form validation, loading states, and error handling 
- Style with a cohesive, professional design system 
- Ensure all interactions work smoothly for user testing

---

## 🧠 Outcome
Your wireframes become a high-fidelity, interactive prototype ready for demonstrations or usability testing.
