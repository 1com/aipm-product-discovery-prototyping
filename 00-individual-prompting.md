# 00 – Individual Exercise: Prompting with Lovable

## 💡 Why this exercise matters
Prompting directly in Lovable helps you move from *idea to prototype* without needing design skills.  
It teaches you to express functionality, user flow, and trust through clear, structured prompts.

## 🎯 Expected outcomes
- A professional prototype (dashboard, landing page, or mobile app)
- Clear visual hierarchy, modern UI, and functional user journey
- Understanding of iterative AI-based prototyping

---

## 🧭 Main Prompt (Fill in the blanks and paste into Lovable)

Create a professional [SaaS dashboard/landing page/mobile app] for [specific target user, e.g., "small business owners managing inventory"]. 

CORE FUNCTIONALITY: 
1. [Primary feature, e.g., "Real-time inventory tracking with low-stock alerts"] 
2. [Secondary feature, e.g., "Sales analytics dashboard with monthly trends"] 
3. [Support feature, e.g., "Supplier contact management with reorder buttons"] 

TARGET USER JOURNEY: 
- Entry point: [e.g., "Dashboard homepage showing key metrics at a glance"] 
- Main action: [e.g., "Update stock levels and view alerts"] 
- Success outcome: [e.g., "Never run out of popular products"] 

DESIGN REQUIREMENTS: 
- Modern, professional UI with clean typography 
- Mobile-responsive layout 
- Professional color scheme (choose appropriate palette) 
- Include realistic sample data and placeholder content 
- Ready for user testing with clear navigation and calls-to-action 

Make this feel like a real product that users would trust and pay for.

---

## 🔄 Iterative Improvement Prompt

Now enhance this prototype to make it more professional and user-friendly:

POLISH IMPROVEMENTS:
- Improve visual hierarchy and make key actions more prominent 
- Add subtle animations and hover effects for better interactivity 
- Include loading states, empty states, and error handling 
- Enhance mobile experience with touch-friendly interactions 

BUSINESS CREDIBILITY:
- Add trust signals (testimonials, security badges, company info) 
- Include proper onboarding flow or help text where needed 
- Make forms more user-friendly with better labels and validation 
- Add realistic pricing or subscription elements if applicable 

Focus on making this feel production-ready and trustworthy.

---

## 🧠 Outcome
A realistic, testable prototype demonstrating professional design and business credibility.
