# AIPM Bootcamp – Day 3: Prototyping with Lovable

## 🎯 Goal
Turn your validated discovery insights (from Day 2) into a tangible, testable prototype using **Lovable.dev** — a GenAI-powered design platform that helps you build realistic, interactive prototypes in minutes.

By the end of this session, you’ll have a professional-looking multi-page prototype ready for feedback and user testing.

---

## 📋 Framework Overview
**Total Time:** ~45 minutes (individual + group)

- **00**: Individual Exercise – Prompting  
- **01**: Individual Exercise – Using Screenshots  
- **02**: Individual Exercise – Figma to Lovable Workflow  
- **03**: Group Exercise – Multi-Page Prototype Challenge  

Each markdown file contains the original Lovable templates, examples, and prompts — plus context on *why each step matters* and *what outcomes to expect*.

## 🚀 How to Use
1. **Individual Work:** Choose one of the first three options to prototype your idea.  
2. **Group Work:** Collaborate on the 3-page challenge (file `03-group-prototype-exercise.md`).  
3. **Present:** Show your prototype to peers for feedback and iteration.  

---

## 🛠️ Tools Needed
- [Lovable.dev](https://lovable.dev)
- Optional: [Figma](https://www.figma.com) with “Wireframe Designer” plugin
- Outputs from Day 2 (Discovery Framework)
- ~45 minutes of focused work
